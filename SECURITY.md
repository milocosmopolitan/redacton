# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/milocosmopolitan/redacton/security/advisories/new) to report a vulnerability privately. The repository setting has been verified as enabled. Ordinary issues and pull requests are public.

Describe the affected version or commit, expected behavior, impact, and reproduction steps using synthetic credentials. Do not include live credentials, private transcripts, or customer data. No response-time or absolute-confidentiality guarantee is made.

Redacton is an experimental Alpha 1 implementation under host qualification. It is not production-ready. The [compatibility report](docs/COMPATIBILITY.md) records exact tested coverage and limitations. Helper tests alone do not establish host interception; model payload, transcript/storage, and UI are separate channels. Original prompts/tool arguments can remain in host storage, and plaintext exists temporarily in memory.

This security route handles vulnerabilities. Use the documented maintainer email in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns. Neither channel implies a response-time or absolute-confidentiality guarantee.
