# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/milocosmopolitan/redacton/security/advisories/new) to report a vulnerability privately. The repository setting has been verified as enabled. Ordinary issues and pull requests are public.

Describe the affected version or commit, expected behavior, impact, and reproduction steps using synthetic credentials. Do not include live credentials, private transcripts, or customer data. No response-time or absolute-confidentiality guarantee is made.

Redacton is at the design/qualification stage; no supported release or verified protection boundary is currently declared. Helper tests alone do not establish host interception. Model payload, transcript/storage, and UI require separate qualification, and plaintext can exist temporarily in memory.

This security route does not establish an independent private conduct-reporting channel. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the current conduct policy; that private channel remains a release requirement.
